# ATBM PTK/RX 临时诊断清理设计

## 目标

结束本轮 PTK 安装与 RX 解密失败定位，移除只为该问题加入的高频诊断，恢复较干净的串口输出。

## 清理范围（方案 A）

- 删除 `[WPA-DIAG]`、`[KEY-DIAG]`、`[RX-DEC]`、`[RX-CLASS3]` 打印。
- 删除仅供上述打印使用的序号、时间戳和计数字段。
- 保留简洁的 `[KEY] PTK ... ret=...` 结果日志。
- PTK 状态推进时不恢复误导性的 `hostapd Timeout` 打印。
- 保留 `[SDIO-IRQ]`、`[SDIO-RX-RECOVER]`、`[APDIAG]` 及 100 ms 恢复保险，继续观察 SDIO 稳定性。

## 行为约束

不修改四次握手、密钥安装、RX 丢包/class3 处理、SDIO IRQ、DHCP、BTStack 或固件下载逻辑。清理后运行行为应与清理前一致，仅减少日志与诊断状态占用。

## 验证

1. 静态搜索确认四组诊断标记和专用字段已删除。
2. 重新构建 ATBM WiFi 静态库，确认编译通过。
3. 主工程由用户在 G+IDE 中编译链接。
