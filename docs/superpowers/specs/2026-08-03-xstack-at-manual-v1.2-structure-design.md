# xStack AT 协议手册 V1.2 结构优化设计

## 目标

将现有 xStack AT 协议手册调整为“先总览、后细分”的客户查阅结构，并全面
修订移除外部品牌名称后产生的生硬语句。协议命令、参数、响应和实现状态保持
不变。

## 文档结构

客户版 DOCX 和 PDF 使用以下顺序：

1. 封面。
2. Command 命令总表。
3. Event 事件总表。
4. 通用协议格式与状态说明。
5. Command 详细说明。
6. Event 详细说明。
7. 命名与格式说明。

不再保留文末“支持状态索引”，避免与开头两个总表重复。

## Command 命令总表

完整列出 79 条命令。每行包含：

- ID，例如 `CMD-001`。
- Command，例如 `AT+PROFILE`。
- 中文功能简述，直接复用经过校订的命令标题。
- 当前状态：已实现、部分实现或待实现。

按现有协议顺序排列，不按状态重新排序。表头跨页重复，状态单元格沿用绿、
黄、红三色。

## Event 事件总表

完整列出 48 类事件。每行包含：

- ID，例如 `EVT-001`。
- Event，例如 `+DEVSTAT`。
- 中文功能简述，直接复用经过校订的事件标题。
- 当前状态：已实现、部分实现或待实现。

按现有协议顺序排列，视觉规则与 Command 总表一致。

## 详细说明

Command 和 Event 详细章节继续保留：

- 支持状态。
- 格式。
- 参数。
- 响应（仅 Command）。
- 中文说明。
- 示例。

详细条目继续按 Profile 分组，ID 与总表一一对应。

## 措辞规则

客户版文档使用独立、自然的 xStack 表述：

- 默认参数直接写“缺省值为……”。
- 当前能力差异直接写“当前 xStack 支持……”或“当前尚未实现……”。
- 不在命令说明中反复写“参考协议定义”“参考协议原文说明”等来源性措辞。
- 原始材料中存在的命名、格式和参数编号差异统一放入“命名与格式说明”。
- 文档正文、封面、副标题和文件元数据均不得出现外部品牌名称。
- 不改变 AT 命令、事件名称、参数值、示例数据和既定支持状态。

## 版本和交付

- 新版本号为 V1.2。
- 交付 DOCX 和 PDF。
- 保留现有 V1.1，不原位覆盖旧文件。

## 验收标准

- Command 总表位于详细命令之前，包含 79 条且 ID 无缺失。
- Event 总表位于详细事件之前，包含 48 条且 ID 无缺失。
- 总表每项包含中文功能简述和支持状态。
- 详细章节仍包含 79 条 Command 和 48 类 Event。
- 文末不存在重复的支持状态索引。
- 客户版正文及文件元数据中的禁用品牌词为零命中。
- DOCX 包结构可正常读取，页型和表格几何保持一致。
- PDF 可提取文本、页数正常，并完成全部页面渲染检查。
